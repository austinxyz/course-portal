怎么参与

加入流程（3 步）

  1. 在微信大群报名——回复"我要加入 XX 小组"，组长会拉你进专属群
  2. 参加第一次 Zoom——每人 1 分钟自我介绍（背景 + 想在这个方向做什么），然后自由讨论
  3. 按自己节奏参与——不强制出勤，有 Zoom 录屏，随时回看

参与方式（自由选）

  • 看：参加 Zoom，看别人演示，吸收灵感
  • 分享：把自己做的 prompt / skill 发到群里，组长整理上传 GitHub
  • 发起项目：有想做的东西，群里喊一声，看谁加入
  • 提交 PR：会 git 的直接 fork 仓库提 PR
内容质量不是门槛——能跑通、对你自己有用就值得分享。组长帮整理格式，你只管发链接或截图。

每月运营节奏

每月 1–2 次 Zoom，约 60 分钟。组长负责组织，Austin 支持首次会议并每月 review GitHub 内容。

第 1 周
组长在微信大群发通知

发本月 Zoom 时间 + 主题，感兴趣的成员报名参加

第 2–3 周
Zoom 小会（60 分钟）

自我介绍 → 本月项目进展 → 问题讨论 → 自愿演示 → 定下次时间

第 4 周
组长整理 + 归档 GitHub

把 Zoom 里分享的好东西（prompt / skill / wiki 笔记）整理上传，其他成员下载即可

第一次 Zoom 怎么开

  1. 每人 1 分钟自我介绍：背景 + 想在这个方向做什么
  2. Austin 或组长演示一个简单成品开场
  3. 自由讨论：大家最想解决什么问题？
  4. 确认下次时间

共享空间 · GitHub

一个公共仓库，按方向分目录，所有付费学员可访问和下载。不需要懂 git——直接下载 zip 或单个文件即可。

github.com/claude-ai-community/community

claude-ai-community/community/ ├── 财富管理/ │ ├── skills/ # .claude/commands/ 文件 │ ├── prompts/ # 提示词模板 │ ├── wiki/ # 知识库条目（Markdown） │ └── 笔记/ # 会议记录、idea、心得 ├── 金融分析/ ├── 内容创作/ └── 其他/

怎么用

  • 下载整个仓库：点页面右上角 Code → Download ZIP，解压后按目录取文件
  • 下载单个文件：进对应目录，点文件名 → 右上角 Download raw file
  • 会 git 的成员：直接 fork → 加文件 → 提 PR，组长 review 后合并

贡献流程（不懂 git 版）

  1. 在微信群发你的 prompt / skill 截图或文字
  2. 组长整理格式，上传到对应目录
  3. 其他成员进 GitHub 下载使用
有好东西不知道怎么上传？直接发群里，说一句"这个可以放 GitHub 吗"，组长来处理。

常见问题

可以加多个小组吗？
可以。但建议先深入一个，把第一次 Zoom 跑起来再看是否加入第二个。
必须参加每次 Zoom 吗？
不强制。每次 Zoom 都有录屏，错过了回看即可。有 Zoom 就在群里报名；没时间就跳过。
我没有什么可分享的，可以只听吗？
完全可以。"只听"也是正当参与方式。看别人演示、提问、给反馈都有价值。
我的领域不在这 4 类里怎么办？
加"其他"小组，或者在微信大群直接喊——如果同一方向的人多，可以另建新群。
小组什么时候正式启动？
7/5 Demo Day 当天宣布并发入群二维码，7 月第 2 周各群开始发第一次 Zoom 通知。
