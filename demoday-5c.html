5C 不只是找工作——它是一台可复用的引擎

读完这篇，你会找到属于自己的 Demo Day 灵感。

📖 5C 方法论原文来自 Nan：From Growth Year to Game Plan →

很多同学知道 5C 是 Nan 的找工作方法论：

C1 方向清晰 → C2 建立底气 → C3 建立人脉 → C4 高效转化 → C5 做出承诺

但这几天我想明白一件事，正好可以帮你们找到 Demo Day 的灵感：5C 根本不是"找工作"专用的，它是一台通用引擎。

5C 的本质

把它抽象出来看，5C 其实是一个「目标驱动的 搜索 → 外联 → 转化」流程：

先想清楚要什么(C1)，把自己准备好(C2)，找到对的人(C3)，高效转化(C4)，然后坚持迭代(C5)。

而几乎所有"我想得到某个机会"的事，都是这个形状。你只要换掉「目标」，同一套引擎就能跑出完全不同的工作流：

  • 目标是全职岗位 → 这就是原版找工作
  • 目标是付费演讲机会（有同学正好在愁这个）→ C1 筛会议、C3 找主办方、C4 定制 pitch
  • 目标是客户（做保险、做咨询、接单）→ C1 锁定人群、C3 触达、C4 跟进成交
  • 目标是学员 / 报名 → 招生本身就是一次 5C
  • 目标是投资人、合作伙伴、供应商 → 同样成立

引擎不变，变的只有四样：目标、去哪找（来源）、怎么打分（筛选标准）、说什么（话术）。

而这正是 AI 的用武之地——发现、筛选、起草、跟进这些又累又碎的活，全可以交给 AI 自动跑；你只负责真正需要人的部分：建立关系、谈条件、最后拍板。

这跟你的 Demo 有什么关系

Demo Day 不需要你做一个很炫的东西，需要的是一个真正解决你自己问题的工作流。而 5C 给了你一个现成的骨架——你不用从零想，只要回答四个问题：

  1. 目标：我最想得到的那个"机会"是什么？（一份工作 / 一批客户 / 一个演讲 / 一个合作）
  2. 来源：这种机会一般出现在哪里？（招聘网站 / 会议 CFP / 行业群 / LinkedIn / 协会名单）
  3. 打分：什么样的算"值得投"？（给不给钱、契合度、地域、难度）
  4. 话术：我要对他们说什么？（为什么是我、为什么是现在）

把这四个变量填进 5C，让 AI 去跑发现、筛选、起草、跟进——这就是一个完整、可演示的 demo。

给你的思考题

你自己最想要的那个"机会"，能不能也套进 5C？

把它写下来，定义清楚那四个变量。你会发现，你已经拥有了一个属于自己的、AI 驱动的工作流——而且它在 Demo Day 之后还能继续帮你赚到时间和钱。

这，才是学会用 AI 的真正方式：不是记住一个模板，而是看懂底层结构，然后把它套到你自己的目标上。
