兴趣小群组长指南

Claude AI 课程 · 学员社群 Phase 2

感谢你愿意带领这个方向的社群。
这份文档说明组长具体要做什么、怎么做、Austin 怎么支持你。

你在做什么

你带领一个 Claude AI 应用方向的学员社群：

  • 组织同方向学员定期碰面（Zoom）
  • 积累这个方向的可复用资源（GitHub）
  • 让愿意贡献的人有地方贡献，让只想用的人有东西可用
你不是内容创作者，不是老师，不是全职维护者。
你是这个方向的第一个探路者，负责把大家的经验汇聚起来。

时间投入

每月约 3–4 小时：

事项时间
组织 + 主持 Zoom 小会（1–2 次）1.5–2h
整理 Zoom 里分享的内容，上传 GitHub0.5–1h
微信群回消息、发通知零碎，随手

无需备课，无需写文章，不要求自己有多高产出。

每月具体怎么做

第 1 周：发通知

在微信群发：

「[方向名] 本月 Zoom：[日期] [时间] PT，感兴趣的回复 +1，我发链接」

Austin 帮你建 Zoom 链接。

第 2–3 周：开会

会议流程（60 分钟）：

时间内容
10 分钟自我介绍 / 近况更新
30 分钟主要议题：本月大家在做什么？遇到什么问题？
15 分钟自愿演示：有做出东西的人 screen share
5 分钟下次时间 + 有没有人想发起合作

不需要准备 PPT。你主持，Austin 会参加前 1–2 次帮你暖场。

第 4 周：整理归档

把会议里有价值的内容整理上传 GitHub：

  • 有人分享的 prompt → 放 prompts/
  • skill 文件 → 放 skills/
  • 一篇总结 / 会议记录 → 放 笔记/
  • 知识性内容 → 放 wiki/

不会 git？直接发给 Austin，帮你传。

GitHub 仓库

仓库地址：github.com/claude-ai-community/community

你负责的目录：[你的方向]/

目录存什么
prompts/prompt 模板，复制即用
skills/Claude Code skill 文件
wiki/知识库条目（Markdown）
笔记/会议记录、idea、心得
原则：轻量存档，不强求质量。
一个会议记录 + 2 个 prompt 就够了。内容会随时间自然积累。

Austin 的支持

  • 前 2 次 Zoom 陪你主持，帮你建立节奏
  • 技术问题随时问，微信直接找我
  • GitHub 上传帮你做，你只负责收集内容
  • 每月 review 一次，看看哪里需要调整

第一次 Zoom 怎么开

时间：7 月中旬（Demo Day 之后）

你需要做的：

  1. 定好时间，Austin 发通知到微信大群
  2. 会议当天按上面流程主持
  3. 结束后把亮点整理发给 Austin

常见问题

Q：没人来怎么办？
第一次不来很正常。持续发通知，做 2–3 次之后自然会有固定参与者。Austin 会帮你在大群里推。
Q：我自己也在学，不够权威怎么办？
组长不是专家，是组织者。你的价值是把大家聚在一起，不是讲课。
Q：大家都很忙，参与度低怎么办？
Zoom 录制下来，放到群里。没来的人可以看录像，下次会来。
Q：这个方向我不太熟怎么办？
你感兴趣就行。Demo Day 上大家已经在做很多东西了，你帮他们找到彼此就够了。
