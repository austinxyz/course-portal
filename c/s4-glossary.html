① 三大方法论框架

缩写/名称全称解释
SEPA Stage Analysis + EPS + Price Action + Accumulation Mark Minervini 的趋势交易框架——判断股票处在 Stage 1-4 哪个阶段，只在 Stage 2（上涨阶段）买入。对应 /stock-entry。
BAIT Behavioral · Analytical · Informational · Technical 课程里的错误定价四维评分框架（借鉴 Mauboussin 思路），核心问题是"市场为什么错了"。每维 0-3 分，总分 /12。对应 /stock-analyze。
Moneyball —（非缩写，借用棒球数据分析的意象） 课程里特指"三情景加权期望值定价"框架：Bull/Base/Bear 三种情景算 EV，判断赔率是否值得下注。对应 /stock-entry + /stock-exit。

② 技术分析术语

缩写全称解释
MAMoving Average移动均线。课件里的 MA50 / MA150 / MA200 指 50/150/200 日均线。
RSRelative Strength相对强度——个股涨幅相对大盘的百分位排名，越高代表越强势（课件要求 >70，最好 85-90+）。
ATRAverage True Range真实波动幅度均值，衡量一只股票的日常波动大小，用来算自适应止损宽度（如 2×ATR14）。
VCPVolatility Contraction Pattern波动收缩形态——股价回调幅度一次比一次浅（如 20%→12%→6%→3%），是理想的入场前信号。
VDUVolume Dry-Up量能干涸——整理阶段成交量持续萎缩，配合 VCP 一起看，代表抛压耗尽。
R/RRisk/Reward Ratio风险回报比。课程铁律：R/R ≥ 2:1 才值得入场（潜在盈利至少是潜在亏损的 2 倍）。
Stage 1-4SEPA 阶段分析Stage 1 蓄势（观望）→ Stage 2 上涨（唯一买入阶段）→ Stage 3 顶部（减仓）→ Stage 4 下跌（持币远离）。
Pivot轴心点 / 突破点股价形态里最关键的买入触发价位，通常是整理区间的上边界。
Gap-Up跳空高开股价开盘直接跳过前一天的价格区间，通常由超预期财报触发，是强烈的基本面确认信号。

③ 财务与估值术语

缩写全称解释
EVExpected Value（本课程语境）期望值 = Bull价×概率 + Base价×概率 + Bear价×概率。⚠️ 注意：金融圈更常见的 EV 缩写是 Enterprise Value（企业价值），本课程特指期望值，别混淆。
YoYYear over Year同比增速——和去年同期比，课件常用来判断营收/EPS 是否在加速增长。
TTMTrailing Twelve Months过去连续 12 个月的滚动数据，比单季度数字更能反映真实经营水平。
TAMTotal Addressable Market总潜在市场规模——赛道的天花板有多高，课件要求 >百亿美元才算"大赛道"。
Backlog订单储备 / 在手订单已签约但还没交付确认收入的订单金额，Backlog > 当年营收是强信号（案例：SMCI）。
13FSEC Form 13F美国证监会（SEC）要求管理规模超 1 亿美元的机构每季度披露持仓的报告，课件用来判断"机构是否在建仓"。
Asymmetry Ratio非对称比= Bull 上涨空间% ÷ Bear 下跌空间%，衡量赔率是否划算，课程要求 ≥ 2:1。

④ 市场结构术语

缩写全称解释
OTCOver-the-Counter场外交易市场——不在 NYSE/Nasdaq 主板挂牌的股票，流动性差，课程铁律：小市值必须排除 OTC。
ETFExchange-Traded Fund交易所交易基金——一篮子股票打包成一支可以像股票一样买卖的基金，用来替代"无合适个股"的赛道。
IPOInitial Public Offering首次公开募股——公司第一次在交易所挂牌上市。
NYSE / NasdaqNew York Stock Exchange / Nasdaq美股两大主板交易所，课程要求候选股必须在这两个交易所挂牌（非 OTC）。
REITReal Estate Investment Trust房地产投资信托——把房地产资产证券化、可以像股票一样交易的基金形式。
PropTechProperty Technology房地产科技——用技术改造房地产交易/管理流程的公司（如课件里的 OPEN、COMP）。

⑤ AI / Skill 工程术语

缩写全称解释
LLMLarge Language Model大语言模型——Claude 这类能理解和生成自然语言的 AI 模型，课程里的"分析层"由 LLM 负责。
MCPModel Context Protocol模型上下文协议——让 AI 连接外部工具/数据源的标准协议。课程刻意不用复杂 MCP，只靠 yfinance 脚本即可完成。
APIApplication Programming Interface应用程序编程接口——程序之间互相调用数据/功能的约定接口，yfinance 就是调用雅虎财经数据的一层 API 封装。
JSONJavaScript Object Notation一种结构化数据格式，课程里 Python 数据层输出的就是 JSON，供 LLM 分析层读取。
SkillClaude Code 自定义命令本课程的核心概念——把专家方法写成一个 .md 文件（如 ticker-scan.md），Claude Code 读取后就能重复执行，即 /ticker-scan 这类斜杠命令。

⑥ 半导体/硬件赛道术语

缩写全称解释
HBMHigh Bandwidth Memory高带宽内存——AI 芯片需要的高速存储器，是"存储/半导体"赛道的核心需求来源。
DRAMDynamic Random Access Memory动态随机存取存储器，常规内存芯片，HBM 是其中的高端形态。
SiCSilicon Carbide（碳化硅）一种耐高压高温的半导体材料，用在功率半导体/电网储能领域，是"电网/储能"赛道的核心技术。
CoWoS / SoICChip-on-Wafer-on-Substrate / System on Integrated Chips台积电的两种先进封装技术，AI 芯片算力提升的关键瓶颈，对应"半导体封装测试"赛道。
