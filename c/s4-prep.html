第 1 步安装 Git

  1. 打开 git-scm.com/download/win
  2. 下载安装包，双击运行，一路点 Next（默认选项即可）
  3. 安装完后打开 PowerShell 或 命令提示符，输入： 
    git --version
  1. 打开 终端（Terminal），输入： 
    xcode-select --install
  2. 弹出对话框点 安装，等待完成（含 Git）
  3. 验证： 
    git --version
✅ 看到类似 git version 2.x.x 即为成功。

第 2 步安装 VS Code

  1. 打开 code.visualstudio.com
  2. 点蓝色 Download 按钮，下载对应系统的安装包
  3. 双击安装，保持默认选项
  4. 安装完打开 VS Code，确认能看到欢迎页即可
课上 VS Code 用来做什么？
  • 打开 stock-analysis-lite 工具包，浏览 Skill 文件结构
  • 查看和编辑 .claude/commands/ 里的 Skill 定义文件
  • 查看 Python 脚本（不需要写 Python，只是看逻辑）

所有代码的实际编写和运行都通过 Claude Code 完成，VS Code 是你的"查看窗口"。

第 3 步安装 Python 3 + yfinance

3a. 检查 Python 是否已安装

打开终端 / PowerShell，输入： 
python --version

如果看到 Python 3.x.x，跳到 3b 直接装 yfinance。
如果报错或显示 Python 2，按下方步骤安装。

  1. 打开 python.org/downloads
  2. 下载最新 Python 3（点黄色大按钮）
  3. 安装时 必须勾选 "Add Python to PATH"（默认不勾，注意！）
  4. 安装完重新开一个 PowerShell 窗口，再运行 python --version
  1. 打开终端，输入： 
    brew install python
    （没有 Homebrew？先运行 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"）
  2. 验证：python3 --version

3b. 安装 yfinance

pip install yfinance

macOS 用户如果 pip 报错，改用 pip3 install yfinance。

✅ 验证：python -c "import yfinance; print('ok')" 输出 ok 即成功。

全部验证（1 分钟）

claude --version          # Claude Code 正常
git --version             # Git 已装
python --version          # Python 3.x
python -c "import yfinance; print('yfinance ok')"
